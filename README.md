# DormEase — Dorm Management System (MVP)

โปรเจกต์เต็ม พร้อมเปิดใน VS Code — React + Vite (frontend) / Node.js + Express (backend) / MySQL (nindamdb)

## โครงสร้างโปรเจกต์
```
dorm-ease/
  database_setup.sql     ← สคริปต์สร้างตาราง MySQL (รันใน phpMyAdmin หรือผ่าน SSH)
  backend/               ← Express API (JWT Auth + MySQL)
  frontend/              ← React + Vite (หน้าเว็บ)
```

## ฟีเจอร์ที่มีในเวอร์ชันนี้
- **Login / Register** — สมัคร/เข้าสู่ระบบ เลือก role: ผู้เช่า หรือ เจ้าของหอพัก (JWT + bcrypt บน MySQL)
- **Dashboard** (เจ้าของหอพัก) — จำนวนห้องทั้งหมด / ห้องว่าง / ห้องมีผู้เช่า / ผู้เช่าทั้งหมด / ยังไม่ชำระ
- **Room Management** — เพิ่ม/แก้ไข/ลบห้อง แสดงสถานะว่าง-ไม่ว่าง
- **Tenant Management** — เพิ่ม/แก้ไข/ลบผู้เช่า จับคู่ผู้เช่ากับห้อง
- **Payment** — บันทึกค่าเช่ารายงวด สลับสถานะ ชำระแล้ว/ยังไม่ชำระ
- **ผู้เช่า (Tenant)** — เห็นเฉพาะ "ห้องของฉัน" และ "ค่าเช่าของฉัน" (อ่านอย่างเดียว)
- **แชทบอทอัตโนมัติมุมซ้ายล่าง** — ตอบคำถามพื้นฐานแบบ keyword matching ไม่ต้องมี AI API key

## วิธีใช้งานครั้งแรก
1. เข้าเว็บ กด **สมัครสมาชิก** เลือก role = **เจ้าของหอพัก** เพื่อสร้างบัญชี Admin คนแรก
2. เข้าสู่ระบบ ไปที่เมนู **Rooms** เพิ่มห้องพัก
3. ไปที่เมนู **Tenants** เพิ่มผู้เช่า (กรอกอีเมลของผู้เช่าไว้ด้วย เพื่อให้ระบบเชื่อมบัญชีอัตโนมัติ) และจับคู่กับห้อง
4. ไปที่เมนู **Payments** บันทึกค่าเช่ารายงวด และกดที่ป้ายสถานะเพื่อสลับ ชำระแล้ว/ยังไม่ชำระ
5. ให้ผู้เช่าสมัครสมาชิกด้วย **อีเมลเดียวกับที่กรอกไว้ในขั้นตอนที่ 3** เลือก role = **ผู้เช่า**
   ระบบจะเชื่อมบัญชีให้อัตโนมัติ ผู้เช่าจะเห็นห้องและค่าเช่าของตัวเองทันทีที่เมนู "ห้องของฉัน" / "ค่าเช่าของฉัน"
