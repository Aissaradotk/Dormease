# DormEase — LINE Desktop Bank Payment Listener

โปรแกรมตรวจจับการแจ้งเตือนเงินเข้าอัตโนมัติจาก **LINE Desktop ของทุกแอปธนาคาร** บนระบบปฏิบัติการ Windows และส่งยอดเงินไปจับคู่บิลในระบบ DormEase เพื่ออนุมัติสถานะเป็น **"✓ ชำระแล้ว (PAID)"** ให้ทันทีแบบเรียลไทม์

---

## 🌟 2 ทางเลือกในการเปิดใช้งานบน Windows

### ทางเลือกที่ 1: โปรแกรม System Tray ข้างนาฬิกา (🌟 แนะนำที่สุด — ไร้จอดำ)
- **ไฟล์:** `LinePaymentListener.pyw` หรือดับเบิลคลิก **`start_listener.bat`**
- **จุดเด่น:**
  - ทำงานเงียบๆ ใน **System Tray (ไอคอนโล่เขียวข้างนาฬิกา Windows)**
  - ไม่มีหน้าต่างจอดำ PowerShell กวนสายตา
  - ตรวจจับหน้าต่าง **ป๊อปอัปสีขาวของ LINE Desktop** จากไลน์แจ้งเตือนของธนาคารที่มุมขวาล่างของจอได้โดยตรง
  - ดับเบิลคลิกที่ไอคอนเพื่อเปิดหน้าต่างควบคุม (Dashboard) และมีปุ่มทดสอบจำลองเงินเข้าของทุกธนาคาร

### ทางเลือกที่ 2: รันผ่าน PowerShell Console (แบบระบบเดิมที่อัปเกรดแล้ว)
- **ไฟล์:** ดับเบิลคลิก **`run_listener.bat`** (รัน `payment_listener.ps1`)
- **จุดเด่น:**
  - หน้าต่าง PowerShell Console สำหรับผู้ที่ชอบดูสถานะแบบ Command-Line
  - อัปเกรดรองรับ **ทุกแอปพลิเคชัน/LINE ของธนาคาร** (Krungthai, SCB, KBank, BBL, ttb, Krungsri, GSB, พร้อมเพย์) เรียบร้อยแล้ว

3. **KBank Live / K PLUS (กสิกรไทย):** *"เงินเข้า 3,850.00 บาท", "รับเงินโอน..."*
4. **Bangkok Bank (กรุงเทพ BBL):** *"เงินโอนเข้าบัญชี ... จำนวน 5,000.00 บาท"*
5. **ttb connect (ทีทีบี):** *"เงินเข้าบัญชี ttb จำนวน 3,500.00 บาท"*
6. **Krungsri Simple (กรุงศรี BAY):** *"มีเงินเข้าบัญชี Krungsri จำนวน 3,700.00 บาท"*
7. **GSB Society (ออมสิน):** *"เงินเข้าบัญชีออมสิน จำนวน 3,500.00 บาท"*
8. **PromptPay (พร้อมเพย์):** *"รับเงินพร้อมเพย์ 3,500.00 บาท"*

## 📁 โครงสร้างไฟล์ในโฟลเดอร์นี้
- **`LinePaymentListener.pyw`**: โปรแกรม System Tray หลัก (Python No-Console)
- **`start_listener.bat`**: ดับเบิลคลิกเพื่อเปิดโปรแกรม System Tray ทันที
- **`payment_listener.ps1`**: สคริปต์ตรวจจับ PowerShell (อัปเกรดรองรับทุกธนาคาร)
- **`run_listener.bat`**: ดับเบิลคลิกเพื่อเปิด PowerShell Listener
- **`config.json`**: ไฟล์ตั้งค่า API Endpoint, API Key, และรายชื่อธนาคารเป้าหมาย
- **`simulate_toast.bat` / `simulate_toast.ps1`**: เครื่องมือจำลองการเด้งแจ้งเตือนบนหน้าจอ
- **`processed_ids.txt`**: บันทึก ID การแจ้งเตือนที่ประมวลผลแล้ว ป้องกันการตัดยอดซ้ำ (Idempotency)
